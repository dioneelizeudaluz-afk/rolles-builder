# Rolles — AI Development Builder

Primeira versão da interface do Rolles.

## O que já funciona
- Criar um projeto localmente
- Escrever prompts
- Gerar um plano local de desenvolvimento
- Guardar projetos no armazenamento do navegador
- Listar e reabrir projetos
- Navegação entre Builder, Projetos, Arquivos e Histórico
- Interface técnica responsiva

## Próximas etapas
1. Conectar uma API de IA externa.
2. Criar autenticação da API.
3. Integrar GitHub/repositórios.
4. Criar editor de código real.
5. Criar preview dos projetos.
6. Integrar Supabase quando necessário.
7. Criar fluxo legítimo de publicação.

O projeto não implementa qualquer mecanismo para contornar créditos, autenticação ou cobrança de terceiros.
